A tiny stack virtual machine in a single main.ts (Node 22): 32-bit wrapping integers, a 256-value stack, branches, calls, 256 words of memory, input/output and all ten traps, answering all 40 instances of a set in one run.

## Run it

```sh
node main.ts
```

Reads /input/<id>/program.bin and input.bin, writes /output/<id>/stdout.bin and exit.txt.
